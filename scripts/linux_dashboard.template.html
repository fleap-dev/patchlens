    How to read this

    Each row of the run is one patch, a fix commit linked to a CVE. A patch has a VIC when PatchLens returned a configuration condition for it.

    Likely stable backport. The commit isn't in the mainline clone, but another commit of the same CVE is. Kernel CVE records list the mainline fix plus one commit per stable branch, so these are copies of a fix the run already analyzed. This is inferred from the CVE records. We haven't checked it against linux-stable.

    Kbuild walk. PatchLens maps each patched file to Kconfig options by walking up the directories and reading each Makefile or Kbuild. We reran two failing samples on a full checkout and got the same error, so these failures come from PatchLens and not from the minimal tree the automation writes.

    Options per VIC counts the distinct names inside defined(…) and $(…). ARCH counts as an option.

    Times. The time_processing_ms and checkout_time_ms columns hold seconds, not milliseconds. This page converts them. Only successful patches have times.
